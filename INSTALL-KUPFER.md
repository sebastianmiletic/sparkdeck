# Sparkdeck configuration for Kupfer

This repository contains a personal Hyprland/Quickshell setup. It was prepared for installation on Kupfer Linux while keeping Phosh available as the touchscreen fallback.

The OnePlus 6 enchilada is not the OnePlus 6T fajita. Review monitor names, orientation, scripts, and hardware-specific settings before enabling them.

Install required packages with the target distribution's package manager, then copy `hypr/`, `quickshell/`, and `foot/` into `~/.config/`. Do not run arbitrary scripts as root. Keep secrets and API keys outside this repository.
